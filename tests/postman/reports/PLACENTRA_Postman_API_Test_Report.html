18. Authentication API Deep-Dive

JWT Token Issuance & Role Claims Audit
The Authentication module executes 16 tests evaluating candidate student, corporate recruiter, and institutional Placement Officer login routines. Successful login calls (POST /api/v1/auth/login/) return HTTP 200 OK with access and refresh tokens. Role claims (role: "student", role: "recruiter", role: "placement_officer") were verified. Token refresh calls (POST /api/v1/auth/token/refresh/) and identity checks (GET /api/v1/auth/me/) confirmed robust token security. All passwords, OTP values, and tokens are masked as [MASKED] in report outputs.

19. Resume API & Binary Stream Verification

Structured Resume Data & PDF Stream Validation
The Resume module tests structured candidate data retrieval (GET /api/v1/students/resume/) and automated binary PDF stream rendering (GET /api/v1/students/resume/download/). The PDF endpoint returns HTTP 200 OK with header Content-Type: application/pdf streaming a non-empty binary document. Unauthenticated access attempts return HTTP 401 Unauthorized, strictly guarding candidate personal information.

20. Business Approval Workflow Enforcement

Multi-Stage Recruiter & Job Posting Authorization Flow
PLACENTRA enforces strict business approval gates: Recruiter Corporate Registration → Officer Verification → Approved Recruiter Status → Job Posting Authorization. Unapproved or student personas attempting to post jobs (POST /api/v1/jobs/) receive HTTP 403 Forbidden ("You do not have permission to perform this action."). Placement Officer approval lists (/placement-officers/recruiters/ and /placement-officers/jobs/) allow institutional officers to review and approve pending corporate entities.
