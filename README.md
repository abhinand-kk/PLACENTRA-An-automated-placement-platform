# PLACENTRA - AI-Powered Campus Placement & Intelligent Candidate Platform

PLACENTRA is an AI-powered campus placement platform connecting students, recruiters, and placement officers for intelligent candidate matching, verified placement drives, and seamless recruitment experiences.

## 🚀 Features

- **Role Variants**:
  - 🎓 **Student**: Build profiles, AI resume analysis, skill evaluation, and job application tracking.
  - 🏢 **Recruiter**: AI candidate matching, candidate ranking, automated shortlisting, and diversity hiring.
  - 🏫 **Placement Officer**: Student verification, placement drive scheduling, recruiters invitation, and analytics reporting.
- **Component Architecture**: Built using modular React components in Vite.
- **Responsive & Modern Design**: Pixel-perfect layout with dark mode themes, micro-interactions, and custom vector icons.

## 🛠️ Setup & Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/abhinand-kk/PLACENTRA-An-automated-placement-platform.git
   cd PLACENTRA-An-automated-placement-platform
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
